# erdflow-site

Generated static files for the ERDFlow website, https://erdflow.app.

This repository holds only the published website output. It is updated by the
ERDFlow publishing workflow; its source is maintained separately and is not
published here. Please do not open pull requests in this repository.

ERDFlow itself is developed at https://github.com/Zain-Orwa/erdflow, where
problems can be reported.
